# Answer exports

Exports from `ClaryfingQuestions.html` land here, one file per round:

```
answers/cyclamen-qa-<YYYY-MM-DD>.json
```

Produced by the **Export for Junam** button on that page. Keep them — they are the
committed audit trail of the user's recorded decisions, and the only copy of an answer
until Junam folds it back into the page as a `seedAnswer`.

Junam reads the **newest** file here. Nothing in this folder is generated by hand, and
nothing here is a source of truth: `ClaryfingQuestions.html` is.
